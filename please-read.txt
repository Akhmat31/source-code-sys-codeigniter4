!Prerequisites for Installing Dependencies!

Before running the dependency installation process, ensure that the following PHP extensions are enabled or installed on your system:

extension=curl
extension=ftp
extension=fileinfo
extension=intl
extension=mbstring
extension=mysqli
extension=odbc
extension=openssl
extension=pdo_mysql
extension=pdo_odbc
extension=sodium

Once you have confirmed that all the extensions above are enabled, run the dependency installation process again.
If an error message still appears after installation, try running the following command on your command line:

[ composer dump-autoload ]

Then, restart your application server. If the issue persists, verify that all PHP extensions are enabled and that the PHP version being used meets the project's requirements.
